## Overview

MeldaProduction MRhythmizerFX applies effects in rhythm using a step sequencer pattern, enabling complex trance gates, tremolo sequences, and rhythmic modulation synchronized to tempo.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **MeldaProduction MRhythmizerFX** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Step Sequencer** | 16-step pattern sequencer with per-step depth and effect amount |
| **Multiple FX** | Gate, volume, pan, and effect parameter modulation per step |
| **Tempo Sync** | All patterns locked to host BPM with musical note divisions |
| **Free Tier** | Core rhythmizer functionality available free from MeldaProduction |
